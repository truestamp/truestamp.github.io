# truestamp.github.io

Landing page for the [Truestamp](https://github.com/truestamp) GitHub organization, served via [GitHub Pages](https://pages.github.com/).

## Local Development

Requires [Caddy](https://caddyserver.com/).

```sh
caddy run
```

Open <http://localhost:8080>.

## Deployment

Push to `master` — GitHub Pages serves the site automatically.
